# Verification report

What each test and benchmark run establishes, with the numbers actually
measured on the reference machine (Python 3.13.5, NumPy 2.1.3,
Matplotlib 3.10.0, Pillow 11.1.0, Windows 11). All artifacts live in
`docs/results/` and are regenerated by `python examples/run_verification.py`
(`run_summary.json` holds the full machine-readable record).

## 1. Test suite (55 tests, ~9 s)

`python -m pytest tests -q`

### Lattice correctness — `tests/test_lattice.py`
| Test | Establishes |
|---|---|
| velocity set layout / exact weights | The stencil is the standard D2Q9 with weights `4/9, 1/9 x4, 1/36 x4`. |
| isotropic moment conditions | `sum w c = 0`, `sum w c_a c_b = cs^2 I` — the quadrature the derivation relies on. |
| opposite-direction map | `c_opp[q] = -c_q` and involution — the reflection rule bounce-back needs. |
| equilibrium moments | `sum f^eq = rho`, `sum c f^eq = rho u` to `1e-13`. |
| Guo source moments | `sum S_q = 0` and `sum S_q c_q = rho g e_x` exactly — the discrete force is what it claims to be. |

### Units and viscosity — `tests/test_units.py`
| Test | Establishes |
|---|---|
| `nu = (tau - 1/2)/3` | The relaxation-time/viscosity relation is exact, `tau <= 1/2` gives non-positive viscosity. |
| conversion round trips | Lattice↔physical viscosity/velocity conversions invert exactly; `dt = cs^2(tau-1/2)dx^2/nu_phys` realises the target viscosity. |
| `dx = H/(ny-2)` | The spacing rule implied by half-way bounce-back. |

### Solver validation and conservation — `tests/test_solver.py`
| Test | Establishes |
|---|---|
| input validation (tau range, grid parity, forcing sign, low-Mach guard, types) | Bad inputs fail loudly with actionable `ChannelLatticeError` messages: `tau` outside `(0.5, 20]`, even `ny`, `ny < 5`, `nx < 4`, `force_g <= 0`, implied `u_max > 0.15`, non-integer grids. |
| geometry conventions | `h = ny-2`, walls at `0.5`/`ny-1.5`, `nu`, `omega`. |
| initial state | Rest at uniform density with the Guo half-force velocity `u = g/2`. |
| mass conservation | After 400 steps the drift stays below `1e-10` relative (measured `~5e-13` in the benchmark). |
| exact discrete momentum balance | At every step, `dP = force impulse + tracked wall exchange` to round-off (`< 1e-10` relative) — collision, forcing, streaming, and bounce-back are mutually consistent. |
| forcing direction | Flow moves in `+x`, no cross-flow. |

## 4. Relaxation-time study (`tau_study.csv`, `tau_study.png`)

`h = 31` fixed, `u_max = 0.06` held fixed, `tau in {0.55..1.5}`:

| tau | nu | rel. L2 | steps |
|---|---|---|---|
| 0.55 | 0.0167 | 1.41e-3 | 116 500 |
| 0.60 | 0.0333 | 1.35e-3 | 60 250 |
| 0.70 | 0.0667 | 1.12e-3 | 31 250 |
| 0.85 | 0.1167 | 4.94e-4 | 18 500 |
| 1.00 | 0.1667 | 4.75e-4 | 13 250 |
| 1.20 | 0.2333 | 2.30e-3 | 9 750 |
| 1.50 | 0.3333 | 6.17e-3 | 7 000 |

The error is U-shaped: it grows toward `tau = 1/2` (bounce-back slip
error large relative to the vanishing viscosity; also the step count
balloons as `h^2/nu`) and toward large `tau` (heavy over-relaxation of
the collision). The flat optimum near `tau ~ 0.9-1.0` is the recommended
operating point for this code.

## 5. What this verification does NOT establish

* **Low-Re laminar regime only.** All runs have Re <= 15 and Ma <= 0.113.
  Nothing here validates turbulent or transitional behaviour, and BGK
  would be the wrong collision operator for wall-bounded turbulence
  anyway (no fixed Prandtl-number behaviour, insufficient stability).
* **BGK tau ~ 1/2 caveat.** Accuracy degrades as `tau -> 1/2`; the
  verified window is `tau in [0.55, 1.5]`. MRT/TRT operators fix this;
  they are out of scope.
* **Straight, lattice-aligned walls only.** Half-way bounce-back on a
  flat wall is second order; curved or inclined boundaries need
  interpolated/bent-link schemes not implemented here.
* **No equation of state beyond weak compressibility.** Density varies by
  O(Ma^2); the incompressible limit is assumed in the reference solution.
* **Unidirectional statistics.** Because the domain is periodic and
  x-uniform, the solution is exactly 1-D; 2-D disturbances (instabilities,
  secondary flow) are outside the verified behaviour.
